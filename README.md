# AI-Powered Virtual Clothing Try-On System

## Overview

This repository contains the final research documentation and presentation developed during my AI/ML Internship at RARITONE.

The project focused on researching and analyzing technologies used in modern AI-powered Virtual Clothing Try-On systems. The work involved studying computer vision techniques, body analysis methods, virtual try-on architectures, datasets, recommendation systems, and future opportunities in fashion technology.

The objective was to understand how Artificial Intelligence and Machine Learning can improve online shopping experiences through virtual fitting solutions and personalized recommendations.

---

## Project Objectives

* Research Human Segmentation techniques
* Study Pose Estimation and Body Landmark Detection
* Analyze Body Measurement Extraction methods
* Explore 2D and 3D Virtual Try-On systems
* Evaluate datasets used in virtual try-on research
* Compare AI models and frameworks
* Design a complete AI workflow for virtual fitting applications
* Identify future improvements for AI-powered fashion platforms

## Key Findings

* Human segmentation and pose estimation form the foundation of virtual try-on systems.
* Body measurements can be approximated using landmark-based approaches.
* 2D virtual try-on systems are easier to implement and computationally efficient.
* 3D virtual try-on systems provide higher realism but require greater computational resources.
* AI-powered recommendation systems can improve user engagement and shopping confidence.
